# NYC Airbnb Data Analysis 🏠📊

## 📌 Project Overview

This project analyzes Airbnb listings in New York City to discover patterns in pricing, room types, boroughs, hosts, reviews, and availability.

The project combines **Python, Excel, Power BI, and data cleaning techniques** to transform raw Airbnb data into useful business insights and interactive visualizations.

## 🛠️ Tools & Technologies

- 🐍 Python
- 📊 Pandas
- 📗 Microsoft Excel
- 🔄 Power Query
- 📈 Power BI
- 📓 Jupyter Notebook

## 📂 Project Files

| File | Description |
|---|---|
| `AB_NYC_2019.csv` | Original Airbnb dataset |
| `NYC_Airbnb_Cleaned.xlsx` | Cleaned and prepared Excel dataset |
| `odc-final-project.ipynb` | Python analysis and data exploration |
| `dashboard ODC.pbix` | Interactive Power BI dashboard |
| `NYC_Airbnb_Presentation.pptx` | Project presentation |
| `github_screenshots/` | Dashboard screenshots |

- Host analysis

## 🚀 How to Explore the Project

1. Open `odc-final-project.ipynb` to review the Python analysis.
2. Open `NYC_Airbnb_Cleaned.xlsx` to explore the cleaned data.
3. Open `dashboard ODC.pbix` with Power BI Desktop to interact with the dashboard.
4. Check the screenshots above for a quick overview of the final results.

## 🎯 Project Goal

The main goal was to turn raw Airbnb data into clear, actionable insights through data cleaning, exploratory analysis, visualization, and dashboard development.
